# 🎧 英文闖關

用真實 YouTube 影片練英文聽力和單字的小遊戲。一部影片 = 一關。

👉 **開始玩：https://viperwick.github.io/english-game/**（手機、電腦都可以）

## 🎮 玩法
- 🎧 **聽力**：聽一句原音，4 句選 1（🐢 可以放慢）
- ✏️ **填空**：聽一句，打出空格的單字
- 🃏 **單字卡**：翻卡片，不記得的會更快再出現
- 🏆 XP、連擊、每日目標、連續天數、星星

進度只存在你自己的瀏覽器裡，不會上傳。
